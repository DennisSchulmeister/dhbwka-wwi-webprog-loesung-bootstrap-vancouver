# Webprogrammierung / Aufgabe / Bootstrap: Vancouver

Dies ist die **Musterlösung** zur Bootstrap-Aufgabe aus der Vorlesung **Webprogrammierung** (Wirtschaftsinformatik, DHBW Karlsruhe), Kategorie *Responsive Webdesign*.

Die Studierenden sollen eine einfache Webseite mit Bootstrap gestalten, um auf diese Weise das Framework und seine Dokumentation kennenzulernen.

Dieses Repository ist Teil der Quellcodes [dhbwka-wwi-webprog-quellcodes](https://github.com/DennisSchulmeister/dhbwka-wwi-webprog-quellcodes) zur Vorlesung Webprogrammierung.
